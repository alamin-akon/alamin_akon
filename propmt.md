The website should present Alamin as a professional:

* Web Designer

# 4. Design Direction

Create a premium, modern, minimal, and visually impressive portfolio.

## Visual Style

Use:

* Clean modern layout
* Strong typography
* Large headings
* Generous spacing
* Soft gradients
* Subtle grid backgrounds
* Modern cards
* Rounded corners
* Elegant shadows
* Glassmorphism only where suitable
* Smooth section transitions
* Clear visual hierarchy
* Professional colour contrast
* Premium agency-style presentation

The design must not look like a generic template.

It should feel custom-designed for a professional Shopify and web designer.

## Recommended Colour Palette

Use a dark modern theme as the main design:

* Background: deep navy or near-black
* Surface: dark blue-grey
* Primary accent: electric blue
* Secondary accent: purple
* Highlight: cyan
* Primary text: white
* Secondary text: light grey
* Border: subtle semi-transparent white

Suggested CSS variables:

```css
--background: #070b14;
--surface: #0d1424;
--surface-light: #121c30;
--primary: #4f7cff;
--secondary: #8b5cf6;
--accent: #22d3ee;
--text-primary: #f8fafc;
--text-secondary: #94a3b8;
--border: rgba(255, 255, 255, 0.08);
```

A light mode may also be included, but the dark mode should be the main visual style.

## Typography

Use a modern Google Font such as:

* Inter
* Manrope
* Plus Jakarta Sans
* Geist

Use one font family consistently throughout the website.

Headings should be bold and visually strong.

Body text should remain highly readable.
